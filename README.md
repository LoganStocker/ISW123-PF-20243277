## Reglas de negocio

1. La reserva dura minimo 1 dia y maximo 30. Fuera de ese rango no se guarda.
2. El deposito es el 40 % del valor total del alquiler (precio por dia x dias).
3. Un vehiculo solo se reserva si esta Disponible. Al reservar pasa a Rentado y al devolverlo vuelve a Disponible. Mantenimiento no se puede reservar.
4. El cliente debe tener cedula y licencia vigentes en la fecha de la reserva.
5. Cada dia de retraso en la devolucion se cobra con un recargo del 20 % del precio por dia.
6. Si el vehiculo se devuelve a tiempo, se devuelve el deposito completo. Si hay recargo, se descuenta del deposito y se devuelve la diferencia. Si el recargo es mayor que el deposito, el cliente paga lo que resta.
